По дефолту index.php точка входа в приложение, там подгружается енвик, автозагрузчик, роуты, затем идет мапинг по эндпоинту
Сиды и миграции в database, запускается через .sh скрипт (папка docker)
папка framework: типо вендора, неизменяемые компоненты системы
папка app: рабочая директория
папка public: ассеты, css, js, smarty шаблоны
